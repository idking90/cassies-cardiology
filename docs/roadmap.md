# Roadmap

## Version 1 Prototype

Goals:
Validate educator workflow.

Features:
- Minimal topic-tile dashboard with Reset Rotation control.
- Session-only completion tracking; completed tiles are greyed out.
- Read-only educator question view.
- Per-topic QR code generation linking to a learner-only response URL.
- Local learner answer submission with no persistence.
- Hardcoded anonymous-response summary for the educator.
- Teaching material pages that also mark their topic complete.

## Version 2

Features:
- Educator login.
- Persistent database storage.
- Content editing interface.
- Image uploads.

## Future

Potential additions:
- Multiple rotations.
- Multiple educators.
- Multiple questions per topic.
- Question history.
- Analytics.
- Additional specialties beyond cardiology.
